# Yandex Fuel Prices для Home Assistant

Интеграция получает цены на топливо (пропан, бензин, ДТ) на заданных заправках из **Яндекс Карт**. На Картах эти цены показываются по данным Яндекс Заправок.

Каждая заправка добавляется через интерфейс HA по ссылке из Яндекс Карт. Для каждой создаётся устройство с двумя сенсорами:

| Сенсор | Что показывает |
|---|---|
| `sensor.<заправка>_propan` | Цена в ₽/л. Пишется в долгосрочную статистику HA, так что по ней строятся графики. Атрибуты: `station`, `address`, `price_updated`, `all_prices` (все виды топлива на этой заправке), `last_fetch_ok`, `latitude`/`longitude` (заправка видна на карте HA) |
| `sensor.<заправка>_tsena_obnovlena` | Когда Яндекс Заправки последний раз обновили цену (диагностический сенсор) |

## Как это работает

Интеграция раз в N минут (по умолчанию 180) скачивает страницу `https://yandex.ru/maps/org/<id>/` и достаёт из встроенного JSON (`<script class="state-view">`) блок `fuelInfo`:

```json
"fuelInfo": {"timestamp": 1790163457,
             "items": [{"name": "Пропан", "price": {"value": 42, "currency": "RUB"}}],
             "source": {"name": "Яндекс.Заправки"}}
```

Если запрос не удался (капча, сеть), сенсор продолжает показывать последнюю известную цену, а атрибут `last_fetch_ok` становится `false`.

> ⚠️ **Нужен российский IP.** Для иностранных IP Яндекс перенаправляет на yandex.com или yandex.pl, и цен там нет. Если HA работает через VPN или прокси, пустите `yandex.ru` мимо них. Иначе при добавлении заправки будет ошибка «Яндекс перенаправил на иностранный домен».

## Установка

1. **HACS:** ⋮ → «Пользовательские репозитории» → `https://github.com/dobriys/yandex-fuel-prices`, тип «Интеграция» → найдите Yandex Fuel Prices → «Скачать».
   Или вручную: скопируйте `custom_components/yandex_fuel_prices` в `/config/custom_components/`.
2. Перезапустите Home Assistant.
3. Откройте **Настройки → Устройства и службы → Добавить интеграцию → Yandex Fuel Prices** и добавьте заправки. Например:

| Поле | Заправка 1 | Заправка 2 | Заправка 3 |
|---|---|---|---|
| Ссылка или ID | `https://yandex.ru/maps/-/AbCdE1-2` | `https://yandex.ru/maps/org/1234567890/` | `9876543210` |
| Топливо | `Пропан` | `АИ-95` | `ДТ` |
| Название | `АГЗС на Садовой` | `АЗС у развязки` | `АЗС Лесная` |

   Ссылку берите в Яндекс Картах: откройте заправку → «Поделиться» → «Скопировать ссылку». Название топлива пишите так, как оно указано на карточке заправки (регистр не важен).

4. Карточка для дашборда: [Yandex Fuel Prices Card](https://github.com/dobriys/yandex-fuel-prices-card) (ставится через HACS, тип «Dashboard»).

Интервал опроса меняется в настройках интеграции («Настроить»), от 30 минут. Цены на газ обновляются примерно раз в сутки, поэтому опрашивать чаще раза в 1–3 часа нет смысла, а капчу от Яндекса так проще получить.
